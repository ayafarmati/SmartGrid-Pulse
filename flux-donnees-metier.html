Séparation temporelle

Médaillon

MERGE idempotent

MERGE gold.Fact_Energy_Load AS target
USING silver.energy_events AS source
ON target.load_key = source.load_key
WHEN MATCHED AND source.ingestion_time > target.ingestion_time
  THEN UPDATE SET ...
WHEN NOT MATCHED
  THEN INSERT (...);

-- Un même event_id rejoué deux fois = une seule ligne Gold.

4. Prix Aya

Le prix exploite explicitement les trois prévisions précédentes, les prix passés et les variables calendaires. Il ne démarre qu'après validation de la compatibilité des sorties amont.

Entraînement : 2015–2017 uniquement, avec validation temporelle walk-forward. Les données 2018 ne sont jamais accessibles au service d'entraînement.
Inférence : chaque observation 2018 validée construit ses features au temps t, charge une version approuvée, puis écrit la prédiction dans Gold.

Gestion temporelle

Event time : heure réelle de l'observation 2018.

Ingestion time : heure d'arrivée dans la plateforme.

Watermark : borne jusqu'à laquelle le traitement considère la fenêtre complète.

Late event : événement reçu après le watermark ; il est réconcilié par un MERGE correctif et invalide le cache concerné.

Dataplex : publie les résultats DQ, le propriétaire, la description et le lineage Bronze→Silver→Gold.
